# Gamification research 
## Why use gamification?
Evolvia is a coding-learning platform, so the gamification system should encourage users to keep learning without making the system too complicated.
## Main Goals 
- Encourage regular coding 
- Reward completing challenges 
- Show user progress 
- Encourage learning consistency
- Give users small achievements to work toward

## Systems to Design 
### XP
XP will represent the user's overall progress.
### Score
Score will represent coding performance and can later be used for rankings or leaderboards.
### Levels
Levels will show how far a user has progressed.
### Streak
Streak will encourage users to code regularly.
### Badges
Badges will reward users for reaching specific achievements.
### Activity Rewards
Different coding activities will give different rewards.
## Design Principles
The system should be:
- Simple
- Fair
- Easy to understand 
- Easy for the backend team to implement
- Motivating for beginners
